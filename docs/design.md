# 设计说明 · 记录 RecordEverything

这份文档记录 v2.0 的视觉改版依据。没有 Figma 文件，规范直接写在这里，代码即实现。

## 1. 问题

v1.x 的界面能用但"廉价"，具体表现在四处：

1. **每行一张卡**。清单里 10 条待办就是 10 个圆角矩形，屏幕被切碎成一块块，看不出层级。
2. **层级只靠颜色深浅**。深色底上色差本来就小，Surface 与 Bg 只差 4%，卡片边界几乎看不见。
3. **字号只有 11/13/15/26 四档**，标题和正文拉不开，"11 月 23 日 · 周一"这种大标题没有存在感。
4. **没有节奏**。所有间距都是 6dp，标题、列表、输入条贴在一起。

## 2. 设计方向

关键词：**纸质手帐的暖、工具的静**。

- 底色用**炭黑偏暖**（`#0D0B09`），RGB 里红 > 绿 > 蓝，避免常见冷调科技黑。
- 金色（`#E5C07A`）只做**强调**：选中态、勾选、关键数字。不做大面积填充，否则廉价。
- 层级用**三层 surface + 发丝线**拉开，不用阴影——深色界面上的阴影看不见，只会糊成一团。
- 标题用**衬线字体**（Android 上是 Noto Serif CJK），日期数字尤其如此；正文保持无衬线，密度优先。
  这是唯一一个"有点野心"的排版决定，目的是让 App 有别于系统默认的 Material 列表。

### 圆角

`sm 12` / `md 16` / `lg 22` / `xl 28`（dp）。分组卡用 `lg`，底部胶囊用 `xl`。

### 字号

| 角色 | 字号 / 行高 | 字体 |
| --- | --- | --- |
| `displayLarge` | 44 / 48 | Serif，`letterSpacing -1` |
| `displaySmall` | 26 / 32 | Serif |
| `titleLarge` | 19 / 26 | Sans SemiBold |
| `titleMedium` | 15 / 22 | Sans Medium |
| `bodyLarge` | 15 / 23 | Sans |
| `bodyMedium` | 13 / 20 | Sans |
| `bodySmall` | 11 / 16 | Sans |
| `labelSmall` | 10 / 14 | Sans Medium，`letterSpacing 1.2`（小标题用大写间距） |

### 间距

4 的倍数：4 / 8 / 12 / 16 / 20 / 24 / 28。页面水平内边距 **18dp**，分组卡内边距 **16dp**，
卡与卡之间 **14dp**，行与行之间靠 **1px 发丝线**分隔而不是空隙。

## 4. 结构改造

### 清单：从"一行一卡"到"一卡一组"

```
┌─ 分组卡（Surface, radius 22, 1px Line 描边）──────────┐
│  ○  写周报                                    ⋯      │
│     ⚡ 17:00 · 工作 · 汇总本周三条进展                │
│  ──────────────────────────────────────────  ← 1px  │
│  ○  给妈妈打电话                              ⋯      │
│     20:00 · 生活                                     │
└──────────────────────────────────────────────────────┘
```

同一分区（过期 / 今天 / 已做完）的待办在**一张卡**里，行间用 `LineSoft` 发丝线。
好处：分区边界一眼可辨；行高统一，滚动时不会闪；卡少了，视觉噪声少一半。

### 今天页：日期成为主角

```
        ┌ 11 月 · 周一 ┐        ← labelSmall，字距 1.2
        │     23       │        ← displayLarge，衬线 44sp
        └──────────────┘
   今天 4 件未完成 · 已做 9 件   ← bodyMedium
   [====== 环形进度 ======]      ← 完成比例
```

大数字用衬线，是这一版最强的识别点。下方一行小字做摘要，再接一个细环表示当日完成度。

### 日历：去掉格子描边

选中日只用**金色实心圆**垫底，今天用**金色描边圆**，其余日期无任何容器。
格子里只保留：日号、农历、圆点。这样一屏 6 周不会出现 42 个框。

### 底部导航：悬浮胶囊

不再是通栏白条，而是一个浮在底部、带 `SurfaceHi` 底与 `Line` 描边的胶囊，
选中项用**金色实心圆 + 深色图标**。输入条浮在胶囊上方 8dp，带金色柔光边。

## 5. 动效

只用两种，都短（150–220ms），不做花活：

- **勾选**：圆圈填充 `animateColorAsState` + 对勾 `scaleIn`
- **出现**：草稿卡 `AnimatedVisibility` + `fadeIn + slideInVertically(24)`
- **数字**：今日完成度环形 `animateFloatAsState`
